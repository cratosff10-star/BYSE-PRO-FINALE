# BYSE PRO — React + TypeScript (Refatorado)

Refatoração modular do protótipo enviado.

## Estrutura
- `src/app`: composição e navegação
- `src/features`: módulos de negócio
- `src/components`: componentes compartilhados
- `src/data`: constantes e dados iniciais
- `src/utils`: utilitários
- `src/types`: modelos TypeScript

## Executar
```bash
npm install
npm run dev
```

## Verificar
```bash
npm run typecheck
npm run build
```
